# MediLocker

MediLocker is an Android app that helps users store and manage their medical records in one place.

### Features
- User login and Google Sign-In
- Upload and view medical records
- Store record details like doctor, hospital, date and condition
- Share medical records
- AI-based Medi Assistant for general health queries

### Built With
- Java
- Android Studio
- Firebase Authentication & Firestore
- Cloudinary
- Gemini API
- OkHttp

### Setup
1. Clone the repository.
2. Open it in Android Studio.
3. Add your Firebase `google-services.json`.
4. Add your Gemini API key to `local.properties`.
5. Build and run the app.
